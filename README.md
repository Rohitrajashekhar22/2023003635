# Notification System

A simple full-stack notification system
.

## Tech Stack

- Frontend: React + Vite + Material UI
- Backend: Node.js + Express
- Database: MySQL
- Logging: Affordmed Logging API

## Features

- View college notifications
- Filter notifications by type
  - Placement
  - Result
  - Event
- Top 10 priority notifications
- MySQL database storage
- Backend REST APIs
- Affordmed logging middleware
- Simple and clean UI

GET    /notifications
GET    /notifications/:id
POST   /notifications
PATCH  /notifications/:id/read
DELETE /notifications/:id
GET    /external-notifications


##NOtification types
- Result
- Placements
- Event\


**How to Run Backend**
cd notification-system/backend
npm install
node server.js

**Backend runs on:**

http://localhost:5000
**
How to Run Frontend**

cd notification-system/frontend
npm install
npm run dev
**
Frontend runs on:**


http://localhost:5173
